# Codex Pulse · 项目脉动

根据最近的对话活动整理 Codex 侧边栏项目顺序，让活跃项目优先显示。

## 设计目标

- 使用对话结束事件触发本地检查，空闲时不轮询。
- 先计算目标顺序；顺序一致时立即退出。
- 重复在同一个项目聊天时，不重复写入相同顺序。
- 本地脚本完成判断，不调用模型。
- 排序对象是默认项目区域中的项目，保留置顶和自定义分区安排。

## 开发约定

每次完成一项修改并验证后，都必须提交 Git。具体规则见 `AGENTS.md`。
